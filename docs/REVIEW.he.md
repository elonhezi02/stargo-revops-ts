# סקירה מקומית

הפרויקט החדש: `/Users/elonhezi/Developer/stargo-revops-ts`.

```sh
npm ci
npm run build
npm start
```

פתח http://127.0.0.1:3002. לפיתוח: `npm run dev`, והממשק ב־http://127.0.0.1:5174.

1. פתח את Anouk ובדוק את חמשת התנאים, הניקוד והראיות. אישור מכירות אינו עוקף תנאי חסר.
2. בדוח השבועי בדוק 6/4/3/2 ופתח שתי ספירות. הסבר למה Felix נספר באירועי השבוע למרות שהגיע מוקדם יותר.
3. הסבר למה historical-reactivation הוא unknown, ואיך expansion מופרד.
4. במסד בדיקות נפרד בלבד (`DATABASE_PATH=runtime/review.sqlite npm start`), הוסף פנייה ואשר בתאריך בתוך השבוע. בדוק שהמספר השתנה; אישור נוכחי לא משנה את השבוע הישן.
5. בדוק פנייה שלילית, עברית וניסיון לשנות את הוראות המערכת. אין לשלוח תשובה בפועל.
6. הפעל Ollama, הרץ עם `LLM_PROVIDER=ollama npm start`, צור בריף ובדוק את מקורות BC/PP.
7. עצור והפעל מחדש; בדוק שמירת הנתונים. הרץ `npm run check` ו־`npm run test:e2e`.
8. השלם בעצמך PROCESS.md ושעות אישיות. תרגל הסבר ושינוי קטן בקוד ללא AI.

לפני הגשה: commit, ואז `npm run package`. הארכיון כולל Git, אך אינו כולל מודלים, מסדים או תלויות מקומיות. אין שליחה אוטומטית.
